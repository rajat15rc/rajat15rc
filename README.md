# Hi, I'm Rajat Choudhary

I am a Data Scientist at the **British Geological Survey (BGS)**, where I build applied machine learning systems for high-frequency sensor data, scientific discovery, and operational analytics. My work sits at the intersection of **machine learning, time-series modelling, scientific computing, and real-world deployment**.

I have worked on production ML pipelines for seismic monitoring, anomaly detection, forecasting, and document AI, using tools such as **Python, AWS, Kubernetes, Kubeflow, MLflow, and Hydra**. My recent work has included crisis-response earthquake monitoring during the **2025 Santorini seismic crisis**, where machine learning-supported catalogues helped reveal previously undetected micro-seismicity.

Alongside my professional work, I have built projects across **sports analytics, recommender systems, NLP, geospatial modelling, computer vision, and probabilistic modelling**. My MSc dissertation focused on **predicting future NBA player performance** using deep learning, and I have also worked on athlete monitoring problems such as **RPE prediction from session data**.
